PATH A · AUTHORIZED FILE ANALYSIS

Analyze an explicitly authorized C file

This path validates and scans a submitted standalone C file without executing it or generating a patch.

01

Authorized intake

One explicitly authorized standalone C source file is accepted under strict file-type, text and 64 KiB size limits.

02

Deterministic analysis

Clang performs syntax-only compilation. Approved local Semgrep rules identify supported security findings.

03

Evidence explanation

A restricted local Qwen model explains sanitized compiler and Semgrep evidence. It does not receive the complete source.

04

Human finding review

A human confirms or rejects the automated conclusion and records a review note. This does not approve a patch or deployment.

PATH B · BASELINE REMEDIATION PROOF

Verify a controlled defensive baseline

This separate path preserves the original vulnerable sample, existing candidate patch, regression inputs and recorded approval.

01

Controlled baseline

02

Existing candidate patch

03

Isolated verification

A restricted Docker harness checks compilation, normal input, ASan and AFL++ crash replays, and static-analysis rules.

04

Approval and memory

Baseline human approval is recorded separately, while verified evidence and SHA-256 hashes support regression memory.
